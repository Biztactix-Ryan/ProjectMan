Add `store_git_state(root, project_dir)` to worktree.py returning a dict: `worktree` (bool), `branch`, `detached`, `upstream`, `ahead`, `behind`, `dirty`, `dirty_count`, `head`. It is the single source of truth every git op consults to decide whether .project is a plain tracked dir on the current branch or a mounted worktree of the projectman branch. Also add `push_branch(root, branch, remote)` that pushes a named branch from the repo root (not from inside the worktree) so relative remote URLs such as `../origin.git` resolve the same way they do for main. Re-point the migration's second push through it.
