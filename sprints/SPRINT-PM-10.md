A hub stops being a second copy of everyone's PM data: each subproject's stories and tasks live at projects/{name}/.project on that repo's own projectman branch, an ID's prefix is enough to find them so the project argument leaves every tool, and a pm write dirties only the file it changed. Alongside, the telemetry claims get a fair test: a capture windowed to sessions after the note-length fix says which Sprint 1 to 9 claims actually hold. Order: US-PM-29 and US-PM-32 are independent and can run first or in parallel; US-PM-31 must land before US-PM-34 (the resolver reads the store map). Left out for capacity: US-PM-33 (2 pts, two worker-flagged leftovers), and the rest of EPIC-PM-5 (US-PM-35 read-only hub, US-PM-36 hub-level epics, US-PM-37 docs) which depend on US-PM-34 and are Sprint 11.
